# 你好，世界 —— 我的第一篇博客

> 2026-05-01

欢迎来到我的数字花园。这是我在「老铛的创世区块」上发表的第一篇文章。

## 为什么要建这个网站

在 2026 年，拥有一个属于自己的网站，就像在数字世界里拥有一块自己的土地。它不受算法推荐的影响，不被平台规则所限制，是一个真正属于你自己的表达空间。

这个网站完全使用原生 HTML、CSS 和 JavaScript 构建，没有任何框架，没有构建工具，甚至没有 npm。这听起来可能有点"返璞归真"，但对我来说，这是一种解放。

## 本站的技术选型

我特意选择了一套精简到极致的技术栈：

- **纯 HTML/CSS/JS** — 零依赖，零构建步骤
- **AES-GCM 加密** — 留言端到端加密，使用浏览器原生 Web Crypto API
- **Markdown 渲染** — 使用 marked.js 通过 CDN 加载
- **EmailJS** — 可选集成，用于留言邮件通知

这样的设计意味着整个网站就是一个文件夹，你可以把它丢到任何静态托管服务上——GitHub Pages、Vercel、Netlify，甚至直接双击 `index.html` 都能在本地运行。
